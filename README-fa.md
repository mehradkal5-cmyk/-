# نسخهٔ فارسی Anatomy Atelier

این خروجی از کد کامپایل‌شده و دارایی‌های عمومی سایت `ant.byteq.id` استخراج شده و با حفظ مدل‌های سه‌بعدی، تصاویر، چیدمان و تعامل‌های اصلی فارسی‌سازی شده است.

## اجرا

روی `start.ps1` راست‌کلیک کنید و **Run with PowerShell** را بزنید، یا از داخل همین پوشه اجرا کنید:

```powershell
.\start.ps1
```

بعد آدرس `http://localhost:4173` را باز کنید. باز کردن مستقیم `index.html` با `file://` برای مدل‌های سه‌بعدی مناسب نیست.

## فارسی‌سازی

- جهت کلی رابط راست‌به‌چپ است.
- فونت محلی و آفلاین «وزیرمتن» استفاده شده است.
- متن‌های رابط، توضیحات ۹ اندام، نقاط راهنما، آزمون، مقایسه و بیماری‌های رایج ترجمه شده‌اند.
- فایل‌های اصلی استخراج‌شده دست‌نخورده مانده‌اند و لایهٔ فارسی در `fa.js` و `fa.css` اعمال می‌شود.
